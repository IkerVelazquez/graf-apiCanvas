## Introducción

La graficación 2D es el área de la computación gráfica encargada de la creación, representación y manipulación de imágenes y objetos en un plano bidimensional. En este tema se estudian los conceptos fundamentales necesarios para comprender cómo se generan y visualizan elementos gráficos mediante coordenadas, formas geométricas, transformaciones y diferentes técnicas de representación.

## Objetivo

Comprender los conceptos básicos de la graficación 2D, así como los elementos y técnicas utilizadas para representar objetos gráficos dentro de un espacio bidimensional.
